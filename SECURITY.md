# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues.

This project is a Drupal extension. Report vulnerabilities that affect Drupal sites through the [Drupal Security Team](https://www.drupal.org/security-team/report-issue) process.

Alternatively, report privately via [GitHub security advisories](https://github.com/AlexSkrypnyk/drupal_helpers/security/advisories/new) for this repository.

Include steps to reproduce, the affected versions, and any known workarounds. Reports are triaged as soon as possible, and coordinated disclosure is appreciated.

## Supported Versions

Security fixes are provided for the latest release of the latest major version only.
